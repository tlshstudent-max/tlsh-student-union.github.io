# 🏛️ 國立斗六高級中學學生會官方網站
> **「凝靜 · 凝聚 · 向心力」** — 打造校園中深邃且充滿質感的數位石澗。

## 開發與管理後台

網站提供免登入的公開資訊與 `/admin/` 幹部工作台。後台支援 Google 登入、管理員／編輯者授權、公告與文件草稿、預覽、發布、下架及修改紀錄；需先設定 Supabase 才能使用真實登入與儲存。

- 完整設定、資料搬移、測試及交接：[SETUP.md](SETUP.md)。
- 本機開發：`npm ci`、`npm run build`、`npm run dev`。
- 自動驗證：`npm test`；瀏覽器流程：`npm run test:browser`。
- `site-config.js` 預設留白，官網持續讀取原有公開試算表。完成資料搬移與權限設定後，才填入 Supabase Project URL 與公開 publishable key。

## 🌊 計畫願景
本站由 **斗六高中學生會** 自主開發，旨在建立一個行政透明、美感並蓄的數位窗口。我們採用「禪意石澗」的視覺語彙，將各組業務模組化，確保行政資料的長久傳承與專業呈現。

## 🛠️ 技術架構
本專案採用純粹且高效的開發模式，確保在任何裝置上皆能展現穩定質感：
* **前端基底**：HTML5 / CSS3 (黑曜石深邃質感佈局)
* **動態渲染**：原生 JavaScript (暖金禪意光影追蹤)
* **資料同步**：學生會 Google Sheets 公開資料層（公告與文件自動讀取）
* **託管平台**：GitHub Pages

## 📂 石澗大樓構造
我們採取「分房隔離」的模組化架構，各部門擁有獨立裝潢與維護空間：
* `index.html`：**大廳** — 官網入口與最新動態中心。
* `president/`：**正副會長室** — 核心願景與意見回饋窗口。
* `activities/`：**活動組** — 校園活動藝廊與企劃展示。
* `pr/`：**公關組** — 對外連結、資源爭取與特約商家資訊。
* `rights/`：**學權組** — 學生權益守護、法規查閱與申訴入口。
* `design/`：**美宣組** — 視覺美學實驗室與設計典藏。
* `docs/`：**文書組** — 行政檔案庫、會議紀錄與法規彙編。

## 💡 維護備忘錄
* **公告更新（後台啟用前）**：在學生會的 [公開資料 Google 試算表](https://docs.google.com/spreadsheets/d/1SBd3jZVA38dv0TSuS-LyKIsSzmGWI9Zyo_7zH5pDNPU/edit) 編輯「最新動態管理」，審核後將狀態改為「公開」。
* **文件更新（後台啟用前）**：在同一份試算表的「公開文件目錄」填寫資料；網站讀取供公開使用的資料欄位。
* **後台啟用後**：統一從幹部工作台管理公告與文件，試算表保留作為搬移前備份，不會與後台雙向同步。
* **交接說明**：完整步驟位於試算表的「操作說明」分頁，不需要修改網站程式碼。
* **風格調整**：全局樣式鎖定於根目錄的 `style.css`；各組專屬裝潢請至該資料夾下的 `style.css` 進行微調。
